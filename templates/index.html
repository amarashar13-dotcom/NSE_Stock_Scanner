IN BOX · CONSOLIDATING INSIDE A NEW BOX · WATCH FOR BREAKOUT
Run a scan
How it works: Darvas box theory on daily candles. A box forms when a stock makes a new 20-day high/low and then trades 3 days without a new high/low — box TOP = the high of the new-high day, box BOTTOM = the lowest low of the pullback. BREAKOUT = close breaks above the box top within the last 8 sessions on ≥1.5× the prior 20-day volume, price still above the box top and above the 200 EMA. Entry = box top, Stop = box bottom, Targets = 1R / 2R / 3R. BREAKDOWN = mirror image on the short side: a box forms after a new 20-day low, close breaks below the box bottom on volume, price still below it and below the 200 EMA. Entry = box bottom, Stop = box top, Targets = 1R / 2R / 3R below entry. IN BOX = a new box formed within the last 8 sessions and price is still consolidating inside it. D52W% = distance below the 52-week high.
